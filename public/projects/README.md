# Project screenshots

Drop exported app screenshots into the folders below, keep the filenames shown here, then rebuild or redeploy the site. A project keeps its illustrated fallback until at least one matching image loads, so screenshots can be added gradually.

Use PNG files at their original Simulator or device resolution. Crop private data and any status-bar details you do not want published.
